# HR Management SQL

A MySQL-based HR Management System designed to practice and demonstrate SQL skills using employee and HR-related data.

## Tech Stack

* MySQL
* MySQL Workbench

## SQL Concepts Covered

* SELECT, WHERE, ORDER BY, LIMIT
* DISTINCT
* Aggregate Functions
* GROUP BY & HAVING
* JOINs
* Subqueries
* Window Functions
* Date Functions

## Database Modules

* Employees
* Departments
* Recruitment
* Attendance
* Payroll
* Leave Requests
* Appraisals

## Project Objective

To analyze employee and HR data using SQL queries and extract meaningful business insights related to salaries, departments, payroll, leaves, attendance, recruitment, and employee performance.
